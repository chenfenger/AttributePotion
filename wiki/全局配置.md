# 全局配置（config.yml）

文件本身每一项都有注释，这里补充取值和相互影响。下表的“默认”是随插件生成的 `config.yml` 里的值。

## 基础

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `debug` | `false` | 输出调试日志，包含匹配和使用药水的耗时 |
| `load-delay` | `60` | 进服后等待多少 tick 再恢复激活中的药水，给属性插件留初始化时间。冷却不受影响 |
| `auto-save-interval` | `300` | 定时存档间隔，单位秒，`0` 关闭。修改后需重启 |
| `run-end-on-offline-expire` | `true` | 药水离线期间到期时，下次进服是否补执行 `end` 动作和 `out-potion` 消息 |
| `attribute-plugin` | `AP3` | `AP2`、`AP3`、`SX2`、`SX3`，或全称 `AttributePlus3`、`SXAttribute2` 等。大版本必须和实际安装的一致 |

## 物品匹配

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `match-mode` | `name` | `name` 物品名，`lore` 任意一行 Lore，`nbt` 字符串 NBT（需要 NBTAPI，缺少时退回 name） |
| `contain` | `true` | `true` 包含即匹配，多个匹配时取 `match` 最长的；`false` 必须完全相等 |
| `anvil-protect` | `true` | `name` 模式下禁止用原版铁砧把普通物品改名成药水 |
| `nbt-key` | `apn` | `nbt` 模式读取的 NBT 键 |
| `nbt-count` | `apn_count` | 次数 NBT 的键，写空字符串关闭 |

选择建议：

- 正式服用 `nbt`。物品名和 Lore 可能被其他插件改写或伪造。
- 必须用 `name` 时，`match` 带颜色符号并把 `contain` 改成 `false`。原版铁砧打不出颜色符号，但提供彩色改名的插件仍然能伪造，`anvil-protect` 拦不住它们。
- `contain: false` 用哈希表查找，药水很多时也不影响性能。

多个药水的 `match` 完全相同时，只有先加载的能被匹配到，后台会提示。

## 其他

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `split` | `<->` | 多段内容的分隔符 |
| `key-slots` | Z、X、C | 按键到槽位名的映射，见[触发与按键](触发与按键.md) |
| `consumable-types` | `APPLE` | 走原版吃喝流程的材料，见[触发与按键](触发与按键.md) |
| `fixed-group-cooldown` | `true` | `true` 组冷却取 `group-cooldowns`，`false` 取本次药水自身的 `cooldown` |
| `group-cooldowns` | - | 组名到秒数。`fixed-group-cooldown` 开启时，药水用了没配置的组，后台会提示，该组没有组冷却 |
| `message-cooldown` | `500` | 同一条消息对同一玩家的最短间隔，单位毫秒 |

## bossbar

药水开启 `optional.bossbar` 时显示。永久药水不显示。

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `title` | `&b%potion% &f剩余 &a%remaining%秒` | 可用 `%potion%`、`%id%`、`%remaining%`、`%time%`、`%percent%` |
| `color` | `BLUE` | PINK、BLUE、RED、GREEN、YELLOW、PURPLE、WHITE，写错时用 BLUE |
| `style` | `SEGMENTED_10` | SOLID、SEGMENTED_6、SEGMENTED_10、SEGMENTED_12、SEGMENTED_20，写错时用 SOLID |
| `update-interval` | `20` | 刷新间隔，单位 tick，最小 1 |

## messages

留空或删除则不发送。`reload` 和 `add-time` 例外：这两条是指令反馈，留空时使用插件内置文本。

| 键 | 时机 | 可用占位符 |
| --- | --- | --- |
| `reload` | `/apn reload` 后 | - |
| `shift` | 要求潜行但没潜行 | - |
| `add-time` | `/apn addTime` 后发给执行者 | `%player%`（目标）、`%potion%`、`%time%` |
| `use-potion` | 使用成功 | `%potion%`、`%id%`、`%time%` |
| `use-deny` | 不满足条件 | `%id%`、`%potion%` |
| `cover-deny` | 不可覆盖且效果还在 | `%id%`、`%potion%` |
| `out-potion` | 药水自然到期 | `%id%`、`%potion%` |
| `on-potion-cooldown` | 药水冷却中 | `%potion%`、`%id%`、`%cooldown%` |
| `on-group-cooldown` | 组冷却中 | `%group%`、`%potion%`、`%id%`、`%cooldown%` |
| `near-potion` | 范围药水发给使用者 | `%range%`、`%playerList%`、`%potion%`、`%id%` |
| `other-potion` | 范围药水发给被波及者 | `%player%`（使用者）、`%potion%`、`%id%` |
| `load-data` | 进服恢复了数据 | - |
| `data-loading` | 数据还没读取完时尝试使用 | - |

除特别说明外，`%player%` 和 `%player_name%` 是接收消息的玩家。
