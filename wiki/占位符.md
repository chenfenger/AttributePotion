# 占位符

需要 PlaceholderAPI，标识符 `apn`。下面的 `<节点>` 是药水节点，可以含下划线。

## 全局

| 占位符 | 说明 |
| --- | --- |
| `%apn_used-potion%` | 激活中的药水节点，逗号分隔 |
| `%apn_used-amount%` | 激活中的药水数量 |

## 单个药水：状态

| 占位符 | 说明 |
| --- | --- |
| `%apn_stats_<节点>%` | 是否激活，`true` 或 `false` |
| `%apn_remain_<节点>%` | 冷却剩余秒数 |
| `%apn_duration_<节点>%` | 效果剩余秒数，永久药水返回 `-1`，未激活返回 `0` |
| `%apn_attr_<节点>%` | 已应用的属性 |

## 单个药水：配置

| 占位符 | 说明 |
| --- | --- |
| `%apn_id_<节点>%` | `match` 内容 |
| `%apn_group_<节点>%` | 药水组 |
| `%apn_time_<节点>%` | 持续时间 |
| `%apn_cooldown_<节点>%` | 冷却时间 |
| `%apn_distance_<节点>%` | 范围半径 |
| `%apn_health-value_<节点>%` | 生命恢复数值 |
| `%apn_health-time_<节点>%` | 生命恢复时长 |
| `%apn_health-mode_<节点>%` | 生命恢复模式 |
| `%apn_mana-value_<节点>%` 等 | 魔力恢复，同上 |
| `%apn_hunger-value_<节点>%` 等 | 饱食度恢复，同上 |
| `%apn_consume_<节点>%` | `optional.consume` |
| `%apn_cover_<节点>%` | `optional.cover` |
| `%apn_shift_<节点>%` | `optional.shift` |
| `%apn_cool_<节点>%` | `optional.cool` |
| `%apn_death_<节点>%` | `optional.death` |
| `%apn_quit_<节点>%` | `optional.quit` |
| `%apn_range_<节点>%` | `optional.range` |
| `%apn_bossbar_<节点>%` | `optional.bossbar` |
| `%apn_break_<节点>%` | `optional.break` |

## 药水组

| 占位符 | 说明 |
| --- | --- |
| `%apn_remain_<组名>%` | 组冷却剩余秒数 |
| `%apn_cooldown_<组名>%` | 组冷却时间 |

只有写在 `group-cooldowns` 里的组可以这样查询。组名和药水节点同名时优先按组解析，请避免同名。
