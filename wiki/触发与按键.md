# 触发与按键

## triggers

| 值 | 说明 |
| --- | --- |
| `ALL` | 以下全部 |
| `LEFT_CLICK_AIR` | 左键空气 |
| `LEFT_CLICK_BLOCK` | 左键方块 |
| `RIGHT_CLICK_AIR` | 右键空气 |
| `RIGHT_CLICK_BLOCK` | 右键方块 |
| `KEY` | 按键。旧写法 `DRAGON`、`DRAGONCORE`、`GERM`、`GERMPLUGIN`、`CLOUD`、`CLOUDPICK` 等同于它 |

- 不写 `triggers` 表示不限制。
- 写了但每一项都无效时，这些操作都不能使用，后台会警告。
- API、指令和原版消耗不受 `triggers` 限制。

## 左右键

副手优先于主手。使用成功后取消事件，不会触发原版行为。

物品是可用的药水、但因冷却或条件用不了时，右键会拦下物品的原版使用（吃、喝、投掷），方块交互（开箱子等）不受影响。

其他插件已禁止这次物品使用（`useItemInHand` 为 DENY，或直接取消事件）时，本插件不处理。

## 原版消耗

`consumable-types` 里的材料，右键时不立即生效，而是走原版吃喝流程，吃完才判定。条件不满足时取消吃喝，物品不消耗。

材料是食物但没写进 `consumable-types` 时，右键立即生效，没有吃的动作。

材料名按服务端版本的写法填。1.13 改过一批名称，例如 1.12.2 的 `MUSHROOM_SOUP` 在 1.13 以上是 `MUSHROOM_STEW`。

## 按键槽位

需要龙核、萌芽、云拾、ArcartX 之一，把药水放进额外槽位后按键使用。

```yaml
# config.yml
key-slots:
  Z: '额外槽位1'
  X: '额外槽位2'
```

```yaml
# 药水
triggers:
  - KEY
```

- 槽位名要和对应插件里的槽位一致。
- 新增按键需要重启，只改槽位名可以 `/apn reload`。
- `key-slots` 的键要写大写，`Z` 和 `KEY_Z` 两种写法都能识别，小写的 `z` 识别不到。

## 长按

```yaml
press: 2.5
triggers:
  - KEY
```

- 按住达到 `press` 秒后自动使用，不需要松开。
- 提前松开时进度按真实时间回退，短时间内再次按下可以接着累计。
- 按下别的已注册按键会打断当前蓄力。
- `press` 只对按键有效。同一药水如果还允许右键，右键是立即生效的。
- 蓄力开始和结束时都会检查条件和冷却。
- 蓄力结束时会重新读取槽位：物品已被拿走或换掉时不使用、不扣除。

### 龙核 HUD

`press-hud.yml` 会发送到客户端的 `Gui/AttributePotion/press-hud.yml`，以 `AttributePotion/press-hud` 打开。

同步给客户端的变量：

| 变量 | 说明 |
| --- | --- |
| `apn_display` | 显示名称，取药水的 `match` |
| `apn_progress` | 进度，0 到 1 |
| `apn_stop` | 是否已停止，`true` 或 `false` |

萌芽、云拾、ArcartX 没有进度显示。
