# 安装与构建

## 运行环境

- Bukkit/Spigot/Paper 1.12.2 到 1.21.x
- 服务端版本要求的 Java 版本（1.12.2 用 Java 8，1.21.x 用 Java 21）

属性插件和按键插件各有自己支持的服务端版本，请确认它们支持你的版本。

## 可选依赖

| 插件 | 用途 | 没有时 |
| --- | --- | --- |
| AttributePlus 2.x / 3.x | 属性加成 | `attributes` 不生效 |
| SX-Attribute 2.x / 3.x | 属性加成 | 同上 |
| PlaceholderAPI | 变量解析、`%apn_xxx%` 占位符 | 只支持 `%player_name%`、`%player%`；用了其他变量的条件会判定失败 |
| NBTAPI | `match-mode: nbt` 和 NBT 次数 | 匹配方式退回 name，次数功能关闭 |
| DragonCore | 按键触发、长按 HUD | 没有按键触发 |
| GermPlugin | 按键触发 | 同上 |
| CloudPick | 按键触发 | 同上 |
| ArcartX | 按键触发 | 同上 |
| SkillAPI | 魔力恢复（优先） | `regen.mana` 不生效 |
| Yetzirah | 魔力恢复 | 同上 |

## 安装

1. 把 jar 放进 `plugins` 目录。
2. 启动服务器，生成 `config.yml`、`press-hud.yml`、`potion/example.yml`。
3. 修改配置，然后执行 `/apn reload` 或重启。

`potion/example.yml` 会被当作真实配置加载，正式使用前请修改或删除。

## 指令

主指令 `/AttributePotion`，别名 `/apn`。权限 `admin`，未配置权限插件时 OP 拥有。

| 指令 | 说明 |
| --- | --- |
| `/apn reload` | 重载配置、药水和属性、魔力接入 |
| `/apn addPotion <玩家> <药水节点>` | 按正常流程给玩家使用，检查条件和冷却 |
| `/apn addPotion <玩家> <药水节点> force` | 强制使用，跳过条件、冷却和 `PotionUseEvent` |
| `/apn addTime <玩家> <药水节点> <秒数>` | 增减激活中药水的剩余时间，负数表示减少。永久药水不可用。旧写法 `addAttr` 等同于它 |

`/apn reload` 不会重新连接数据库，也不会重新注册按键。修改 `mysql`、`auto-save-interval`，或新增 `key-slots` 里的按键后需要重启。

## 从源码构建

项目使用 Gradle 8.7，目标 Java 8。

部分依赖没有公开仓库，需要先把 jar 放进项目根目录的 `libs/`（已被 `.gitignore` 忽略，不要提交）：

- AttributePlus 2.x 和 3.x
- SX-Attribute 2.x 和 3.x
- DragonCore
- GermPlugin

本次修复核对编译时用的版本：AttributePlus 2.3.7 和 3.3.3.0，SX-Attribute 2.0.3 和 3.8.2，DragonCore 2.6.2.9，GermPlugin 4.4.1-4。

CloudPick、ArcartX、SkillAPI、Yetzirah 走反射，不需要放进 `libs/`。

```bash
./gradlew build      # Windows 用 gradlew.bat build
```

产物在 `build/libs/AttributePotion-版本号.jar`。

jar 内置 HikariCP、Gson、exp4j，但这些库没有做包名重定位。**数据库驱动不内置**，使用服务端自带的 SQLite 和 MySQL 驱动。默认的 `com.mysql.jdbc.Driver` 在 1.12.2 和 1.21.11 上都能用；`com.mysql.cj.jdbc.Driver` 只有高版本服务端自带。
