# 药水配置

药水放在 `plugins/AttributePotion/potion/`（旧目录 `potions/` 也会读取），子目录下的 `.yml` 同样加载。一个文件可以写多个药水，顶层键就是药水节点。

单个药水写错只跳过它自己，后台输出警告，不影响其他药水。

## 字段

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `match` | 节点名 | 识别物品用的内容，`&` 转颜色符号。旧写法 `id` 也可以 |
| `group` | 无 | 所属药水组 |
| `cooldown` | `0` | 自身冷却，单位秒，可写小数 |
| `press` | `0` | 按键长按秒数，只对按键触发有效 |
| `triggers` | 不限制 | 见[触发与按键](触发与按键.md) |
| `conditions` | 无 | 见[条件与动作](条件与动作.md) |
| `time` | `0` | 持续秒数，含义见下表 |
| `attributes` | 无 | 属性 |
| `effects` | 无 | 原版效果 |
| `regen` | 无 | 恢复效果 |
| `actions` | 无 | 动作（旧写法 `command`），见[条件与动作](条件与动作.md) |
| `distance` | `0` | 范围半径，单位格，配合 `optional.range` |
| `optional` | - | 开关选项 |

### time 的三种取值

| 取值 | 含义 | attributes、tick | effects | regen |
| --- | --- | --- | --- | --- |
| 大于 0 | 持续指定秒数 | 持续到结束 | 不超过 `time` | 不超过 `time` |
| `0` | 瞬时 | 约 1 秒内结束，不建议配置 | 按自己写的时长，不提前移除 | 只恢复一次 |
| `-1` | 永久 | 持续到被移除 | 写 `{time}` 时持续到被移除 | 写 `{time}` 时持续到被移除 |

到期检查每秒一次，所以属性和 `tick` 动作可能比 `time` 多持续不到 1 秒。

## attributes

```yaml
attributes:
  物理伤害: "100"
  生命力: "%player_level%*2+100"
  暴击几率: "0.05"
```

- 值先替换变量，再按四则运算计算，结果保留 4 位小数。
- 算不出来时原样传给属性插件。
- 不支持 `xx-xx` 范围写法，`10-20` 会算成 `-10`。
- 数值在使用时算好并保存，之后变量变化不会刷新。

## effects

```yaml
effects:
  NIGHT_VISION: '1<->10'
  SPEED: '2<->{time}'
```

格式 `等级<->持续秒数`，等级从 1 开始。`{time}` 取药水的 `time`。持续秒数超过 `time` 时截断到 `time`，后台输出警告。

- 药水被提前移除时（`/apn addTime` 减到 0、API 移除、`optional.death`、`optional.quit`、覆盖使用），等级相同的效果会一起移除。其他来源给的不同等级效果不受影响。
- 进服恢复时只补剩余时长，不会重新给满。
- 死亡时原版会清空效果，`death: false` 的药水在复活后补上剩余时长。
- 用 `/apn addTime` 延长药水时，时长覆盖药水全程的效果会一起延长；只持续一段时间的效果不延长。

## regen

```yaml
regen:
  health: '10<->5<->2'
  mana: '10<->{time}<->1'
  hunger: '2<->5<->0'
```

格式 `数值<->持续秒数<->模式`，格式错误时跳过并警告。

| 模式 | 含义 |
| --- | --- |
| `0` | 固定数值 |
| `1` | 当前值的百分比 |
| `2` | 最大值的百分比 |

- 使用时立即恢复一次，之后每秒一次。持续 5 秒共恢复 5 次。
- 持续秒数写 `0` 只恢复一次。
- 数值可以为负，表示扣除。扣血可以把玩家扣死，不触发伤害事件。
- 玩家死亡期间跳过恢复，时间照常流逝。
- 下线期间错过的恢复不补发。
- `mana` 需要 SkillAPI 或 Yetzirah，都有时用 SkillAPI。

## optional

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `consume` | `true` | 使用后是否消耗物品 |
| `cover` | `true` | 效果还在时能否再次使用。再次使用会先结束旧效果并执行 `end` 动作 |
| `shift` | `false` | 是否需要潜行 |
| `death` | `false` | 死亡时是否结束药水并执行 `end`。对永久药水无效 |
| `quit` | `false` | 下线时是否结束药水并执行 `end`。`false` 时存档，时间在离线期间继续流逝 |
| `cool` | `false` | 是否让物品进入原版冷却，需要 `cooldown` 大于 0。同材料的所有物品一起冷却，期间客户端不能右键使用这种物品。只有带物品的使用会触发，`/apn addPotion` 和按节点的 API 没有物品，不触发 |
| `range` | `false` | 是否让 `distance` 内的其他玩家也获得效果 |
| `bossbar` | `false` | 是否显示剩余时间 BossBar |
| `break` | `false` | NBT 次数用完时是否移除物品 |

### 范围药水

- 只影响同世界、半径内、存活的其他玩家。
- 被波及者不检查条件，不占用自己的冷却，不发 `use-potion` 消息，只发 `other-potion`。
- 被波及者会执行 `success` 动作和 `PotionApplyEvent`。如果 `success` 里有发奖励，每个被波及者都会领到。
- `cover: false` 时，已有该效果的玩家不会被波及。

## NBT 次数

```yaml
# config.yml
nbt-count: 'apn_count'
```

物品带 `apn_count: 10` 这样的整数 NBT 时，每次使用扣 1 次，不扣物品数量。次数为 0 后不能再使用。`break: true` 时用完移除物品。

同一堆物品共享 NBT，请用不可叠加的物品。没有这个 NBT 的物品按普通方式扣数量。
